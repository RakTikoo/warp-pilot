## G5-1 — f(T) relocation = ghost identity

**Claim.** On the T≡0 BHL wormhole background the quadratic tensor action is
exactly f_T(0) × (TEGR tensor action), so the matter-legality condition
f_T(0) < 0 is identically the tensor-ghost sign (kinetic coefficient −1, c_T² = 1).

### Method (mine)
1. **Background + EC sign bookkeeping from the paper's printed equations.**
   Eq.(11) torsion scalar with Eq.(26) shape β = r₀²/r and Eq.(27) redshift
   e^a = (1+s)/2, s = √(1−r₀²/r²): I verified symbolically that
   r a′ = (1−s)/s, so the second factor of Eq.(11), (e^{b/2} − 1 − r a′), vanishes
   identically — T ≡ 0 by algebra, not by numerics. EC sign from the paper's own
   throat equations: Eq.(22) with f(0) = 0 gives 4πρ|r₀ = β′₀ f_T(0)/(2r₀²) with
   β′₀ = −1; Eq.(23) gives 4π(ρ+p_r)|r₀ = −(β − rβ′) f_T(0)/(2r³)|r₀ with
   (β − rβ′) = 2r₀ > 0 (flare-out). Both throat quantities are ∝ −f_T(0):
   **ρ > 0 and NEC1 > 0 at the throat iff f_T(0) < 0** — the sign condition
   arises from the background equations exactly as claimed.
2. **Tensor action by explicit expansion (fresh).** With sympy I built the
   Weitzenböck torsion scalar from its definition
   T = ¼T^{ρμν}T_{ρμν} + ½T^{ρμν}T_{νμρ} − T^{ρμ}_ρ T^ν_{νμ} for a Minkowski
   tetrad carrying a TT perturbation h_xx = −h_yy = ε(t,z), and expanded in a
   bookkeeping parameter λ. Result (exact, symbolic):
   **T = λ²·½(ε̇² − ε′²) + O(λ³)** — there is **no linear term at all**.
   Hence for f(T) = f(0) + f_T(0)T + ½f_TT(0)T² + …, the quadratic tensor action
   receives (i) f_T(0)·(quadratic T) and (ii) ½f_TT(0)·(δ₁T)² = 0 for tensor
   modes: **S₂^tensor[f(T)] = f_T(0) · S₂^tensor[TEGR] exactly**, f_TT cannot
   enter. The step from the Minkowski realisation to the BHL background is the
   standard linear scalar–vector–tensor decoupling on a spherically symmetric
   background: δ₁T is a scalar-sector quantity and cannot be sourced linearly
   by tensor harmonics, so δ₁T|_tensor = 0 there too; and on a T ≡ const
   background the TEGR quadratic form is the only structure available. Kinetic
   and gradient coefficients are both ∝ f_T(0) with the healthy TEGR ratio, so
   **c_T² = 1** and the EOM is unchanged (the factor cancels) — a pure
   negative-energy ghost when f_T(0) < 0.
