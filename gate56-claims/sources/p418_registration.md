and the carrying cost are NOT independent.
Phase 406/414's base B1 (static joint
+6.257022×10⁻⁶, 4.48× Phase 400's base margin)

(joint −4.604584×10⁻⁶, frame-invariant). A base
optimised for the static level is not thereby
a carrying base.

THIS phase optimises the base FOR THE SHIFTED
PROBLEM: a JOINT optimisation over (base
scalings μ_N, μ_M × base corrections vN, vM ×
shift shape vS) with the objective THE CARRIED
JOINT ITSELF — maximise the band joint
(NEC/WEC/DEC, SET-244, band [10, 20]) at the
SS7 criterion peak (0.4426742490267404)
directly, under PEN400 pricing (SS4). The
shape is free (K_S = 9, gated K_S = 17, Phase
405's registration form). The base is free in
the union box of SS4. The search is SEEDED
FROM BOTH ENDS: 400's base + 405's winner (the
proven carrier) and B1 + its Part-2 shapes
(the proven non-carrier) — the walks must be
able to move from either seed.

SECOND READ: at the best carried point found,

## SS5. The search pattern

CD FORM (all blocks). Coordinate descent in
the lineage's form: at each step level, sweep
every coordinate of the block with ±step,
keep the best improving feasible screen as
the new incumbent, proceed to the next level.
Step sets: vS (0.05, 0.02, 0.008) ×
max(1, P/CRIT) (412 SS5); vN/vM additive
(0.03, 0.012, 0.005); μ multiplicative
×(1 ± δ), δ ∈ (0.04, 0.016, 0.006). NM
polish: scipy Nelder-Mead, fatol 1e-9;
shape-only xatol 1e-3 × max(1, P/CRIT),
maxfev 120 (412's form); joint-vector
xatol 1e-3, maxfev 200.

STAGE S — SEEDS (≤ 12 screens). At P = CRIT:
  S-A: 400's base (native K_B = 17) + G50
  shape — the proven carrier through the
  search path.
  S-B: B1 (native K_B = 9) + B1's T1 winner
  shape (K_S = 17, its native rung) — the
  proven non-carrier through the search path.
  S-C: B1 + G50 shape (414's seeded datum,
  −5.503912×10⁻⁵, to be reproduced through
  the search path).
  S-D: 400's base + B1's T1 winner shape
  (K_S = 17) — the cross-seed.
  S-E: 400's base at K_B = 9 (REP-418-K9's
  resample) + G50 shape — Stage A's 400-side
  start.
Each seed screen is stored with its full
configuration.

STAGE T — THE TRANSECT (cap 240 screens).
Bases at t ∈ {0, 0.2, 0.4, 0.6, 0.8, 1} on
the segment 400-side → B1 in the K_B = 9
representation: μ(t) linear; vN(t), vM(t)
linear between the resampled-400-K9
corrections and B1's. At each t: the static
read (vS ≡ 0, 1 screen) and a shape CD from
the G50 shape (≤ 36 screens including the
seed screen at that base). Record per t:
(static joint, carried incumbent joint,
spend = static − carried, the incumbent's
shape). The transect is a measured slice of
the carried landscape, labelled as a slice.

STAGE A — THE JOINT HUNT AT K_B = 9
(cap 800 screens). Starts: the best two
distinct points (by score) among {S-E, the
best transect incumbent, the B1-side best of
S-B/S-C}. From each start, alternating
rounds (≤ 4 rounds; a round that improves
the incumbent score by < 1×10⁻⁹ ends that
start's rounds): SHAPE block (CD on vS +
shape NM) then BASE block (CD on (μ_N, μ_M)
then on (vN, vM)). After round 1 of the
first start, one JOINT NM polish (maxfev
200) on the full vector; a second joint NM
from the overall incumbent at the stage's
end if the first moved it. Every screen
stores its full configuration (base + shape),
so the stage's screen cloud is itself a
landscape sample.

STAGE B — THE EXACT 400 BASE, IN PLACE
(K_B = 17; cap 350 screens). Start: S-A's
configuration (or Stage A's incumbent
resampled to K_B = 17, if it scores higher
as a start — the resample is a representation
move, recorded). BASE block CD at the
(0.012, 0.005) vN/vM levels and all μ levels,
then SHAPE block CD, then one JOINT NM
(maxfev 200). Purpose: test whether the
exact proven base — not its K9 shadow — can
be improved in place at the carried
objective.

STAGE G — THE K_S = 17 GATE (cap 250
screens). Runs IFF the best confirmed
criterion joint after Stages A+B is
≤ J1_400. At the incumbent's base (its
native K_B): the shape K_S = 17 arm in
412's gate form (warm starts = the
incumbent's shape sampled at the 17 knots
and the G50 shape at 17 knots; CD + NM),
then a short BASE block (≤ 60 screens) at
K_S = 17. If the gate does not trigger, the
memo says so.

STAGE R — THE 2× READ (cap 300 screens).
At the best carried point overall (by
confirmed criterion joint; its base frozen):
shape re-optimisation at P = 2×CRIT in 412's
per-rung pattern (seeds: the incumbent
shape, the G50 shape, the H2 seed; CD steps
×2; NM maxfev 120, xatol ×2; box 1.610),
K_S = 9; the K_S = 17 gate at 2× runs iff
the K_S = 9 incumbent joint < 0 there
(412's form, within the cap). The 2× read on
400's base itself is the stored bar J2_400
(SS3's CTL-418-PSTAR) — it is not re-searched.

TOTAL CAP: 2200 screens. If the cap binds
mid-stage, the verdict is COST-BOUNDED with

398/405/406/414 form). Confirmation reads
